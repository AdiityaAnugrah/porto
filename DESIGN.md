# Aditya portfolio redesign

Reference: https://antislop.ai.id/ (retrieved HTML, CSS, and Open Graph preview).
Direction: cinematic photographic introduction, compact top navigation, oversized calm typography, then generous readable content. Adapt the composition, not the reference's artwork or product copy.
Dial: ENERGY 2 / RHYTHM 3 / MOTION 2.


Palette: ink #191518, paper #f7f6f4, white #ffffff, secondary #625b60, warm accent #a23f38. Hero has a burgundy contrast scrim to echo the reference and keep white type readable. Accent marks active navigation, categories and primary actions.
Type: locally bundled Inter for content; Space Grotesk for developer identity and headings. No remote font dependency.
Layout: full-width hero; image-led selected work; contrasting profile section; quieter journal list. Interior pages use normal document scrolling and tailored content rather than desktop-window simulation.
Photo: reuse existing public/assets/me-sunset.avif and JPEG. No invented identity assets, testimonials, client counts or outcome numbers.
Motion: the original AA mark assembles in 2.05 seconds, then rests. It automatically repeats every 20 seconds only while the mark is visible and the tab is active. It is decorative, with no replay button or hover target. The header and footer show only Aditya Anugrah's name; the hero owns the AA symbol. Content sections reveal once as they enter the viewport, with short staggered timing; the hero photograph drifts slightly with scrolling. Utility forms remain static. Reduced motion disables the repeating logo, reveal and photographic drift; focused content and print output remain visible.
Sound: original Web Audio synthesis with a quiet crystalline hover tick and a distinct three-note activation cue, inspired by console UI rather than copied PS5 recordings. Important public navigation, project links and primary actions are audible after the first browser gesture. No audio on scroll, decorative logos, or transaction/admin form controls. Hover is rate-limited; touch does not get duplicate hover audio. A single compact mute control remembers the visitor's preference. No music, autoplay audio file, sound library or external download.
Brand wordmark: the navbar name builds once on initial mount as A, A A, Aditya A, then Aditya Anugrah in 2.55 seconds. An invisible full-name sizer reserves the final width throughout; the accessible link name stays constant. No extra logo, sound, replay button, route-change replay or indefinite loop. Reduced motion shows the complete name immediately.
Selective audio: hover/focus cues are limited to the primary hero CTA, navbar project CTA and explicitly primary interior links. Brand, navigation menus, language switch, project cards, article links, filters and ordinary text are silent on hover. Activation cues remain only on primary actions, hero actions, project cards, service enquiry links and contact methods. The existing mute preference still applies.
Navigation: existing destinations only. Native mobile disclosure; language switch preserves path, query and hash.
Utility screens: retain API contracts and business logic; same top navigation, muted dark surfaces, warm accent, readable inputs and footer.
Review: removed scattered labels, glowing grid, nested scroll windows and uniformly glass cards. Glass is reserved for top navigation; content surfaces are opaque. Preserve source project/article content rather than inventing results.
Personal activity: About restores an explicit Gaming & music section beneath the professional profile. Steam identity/current game, PUBG handle/recent match entries and Spotify current/recent tracks reuse the existing API contracts. Quiet opaque cards match the reading surface, with platform icons only as identifiers. No fabricated ranks, wins, offline states on request failures, unrelated profile accounts, audio playback or hover sounds. Independent loading, unavailable/empty, retry and image fallbacks remain visible. Requests start near the section, refresh each minute while visible, and stop when unmounted/offscreen; reduced motion needs no additional animation.



Tech-network hero: the explicit direction is minimal, clean, premium, dark and futuristic, with the name and full-stack profession as the main visual hierarchy. Aditya Anugrah is now the h1 instead of a generic product tagline; a quiet steel-blue node network supports it from the right. The background represents interconnected frontend/backend systems: sparse deterministic points in actual x/y/z space, perspective projection, bounded node degrees, thin depth-faded edges and soft local highlights rather than a glowing grid. Canvas 2D projects the 3D coordinates without a WebGL engine or model downloads. Use 38 nodes at desktop / 26 in narrow containers, 30/20fps draw caps, DPR <=1.5, slow rotation and lightly smoothed cursor response only on Home. About/Projects preserve the earlier ambient-background role without pointer controls. Hidden/offscreen canvases stop; reduced motion gets one static rendering and no cursor or typography travel. The static SVG network remains available if canvas initialization fails. No replay controls, instructions, mini-game, sounds or foreground props. Three.js and the previous glass models are removed. The two name lines retain quiet scroll/word-hover response without competing with reading or CTAs. Existing Steam/PUBG/Spotify data and all business forms remain unchanged.
Node-detail revision: restore the established Dari ide, jadi / produk digital headline and its original font scale; keep Aditya Anugrah / Full-stack developer in the identity line. Three quiet named network nodes now reveal developer, gaming and music details only after selection. Native 44px buttons follow projected nodes on desktop, clamp within the viewport, and dock as three small nodes above the mobile footer to avoid covering text. Motion holds on pointer hover, keyboard focus and open dialogs so targets remain usable. Native dialog handles focus containment, Escape, close button, backdrop and focus return; localized links lead to real projects or the existing personal-activity section. No invented stats, playlists, genres, ranks or mini-game. About remains an ambient background without detail controls.
PC-profile setup (current direction, supersedes the network scene): Home and the ambient About/Projects backgrounds use a procedural walnut/ivory PC desk again. The monitor has two actual screen tabs, Work/Kerja and Gaming, backed by mode state and raycast UV hit areas. Mechanical key meshes respond to pressing and open verified professional details; the curved white controller opens gaming details and switches the illustrated screen to Gaming; speakers open music details. No mini-game, fake activity counters, hover notices, replay panel or drag instructions. Transparent native hotspots duplicate object actions for keyboard/touch use; narrow screens expose two small mode tabs for comfortable targets. The existing headline typography and desktop 100svh hero remain unchanged. The scene loads on approach, caps DPR at 1.5, renders on invalidation, stops hidden/offscreen, respects reduced motion and disposes geometry/material/texture resources on unmount. Native profile dialogs lock page scrolling, ignore stale StrictMode close events, close only on intentional backdrop clicks and restore focus. Lazy About hash navigation waits for the actual section instead of a fixed 100ms timer; malformed hashes no longer crash rendering. Original Steam/PUBG/Spotify activity stays intact.
Gaming-desk revision: replace the plain wood slab with a chamfered black metal desktop, split cyan/magenta perimeter LED rails, illuminated desk-mat/keyboard borders, foot accents, PC fan rings and side rails. Two short-range point lights produce real under-desk/floor spill; no bloom pipeline or perpetual fan render loop. RGB colors are now an explicit user-requested hardware identity, not a global site palette change. Gaming mode increases illumination modestly. Remove the detached mobile Work/Gaming buttons entirely from rendered layout/accessibility flow; mode selection remains on the raycast monitor texture. Keep object-detail interactions, established typography and full desktop viewport coverage.

Living-pages revision: replace remote monitor video with local canvas loops (12-second code-editor typing and a slow gaming ambience), capped at 12fps without redrawing WebGL. Monitor selection still switches modes. Hidden/offscreen loops pause; reduced motion renders a still frame. Preserve the headline, fonts and scale: a small word-stagger pulse begins after six visible seconds, then repeats after an 18-second rest. Project imagery gets restrained pointer tilt, parallax and sheen, plus keyboard focus and a static touch/reduced-motion path. ArchivePage supplies one ambient PC backdrop to remaining public page headers; utility routes get a quieter noninteractive backdrop. No added hover audio, mini-game, notices, remote video requests or mobile mode buttons.
