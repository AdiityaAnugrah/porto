Cara Main

Ikuti tiga langkah ini. Cocok untuk pemain baru yang belum pernah masuk server public.

Langkah 01

Tambah server

Buka Multiplayer, pilih Add Server, lalu isi alamat dengan play.adityaanugrah.me.

Langkah 02

Masuk server

Pakai Minecraft Java Edition atau TLauncher. Pastikan versi client masih di keluarga 1.21.x.

Langkah 03

Register password

Saat pertama masuk, daftarkan password khusus server. Jangan pakai password akun penting.

Command Login

Command ini diketik di chat Minecraft. Tombol copy membantu pemain awam agar tidak salah format.

Pemain Baru

Daftar akun

Ganti password123 dengan password kamu sendiri.

/register password123 password123
Sudah Daftar

Login ulang

Pakai password yang sama dengan waktu daftar.

/login password123
Ingat

Jaga username

Karena server public dan support TLauncher, login/register wajib untuk melindungi nama pemain.

Jika kamu login dari koneksi yang sama, server bisa mengingat sesi sementara. Kalau tetap diminta login, cukup pakai command login di atas.

Fitur Server

Plugin inti dipilih supaya server tetap mudah dimasuki, tapi masih punya proteksi dasar.

AuthMe

Login untuk public

Username pemain lebih aman walaupun server menerima pemain TLauncher.

ViaVersion

Multi versi 1.21.x

Memudahkan pemain masuk dengan variasi client yang masih kompatibel.

Proteksi

Anti-cheat dan rollback

GrimAC dan CoreProtect membantu mengurangi cheat serta memeriksa perubahan blok.

Support server

Support bersifat sukarela untuk biaya VPS, domain, dan maintenance. Tidak menjual rank, item, atau benefit pay-to-win.
