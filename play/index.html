Cara Main

Langkah 01

Tambah server

Buka Multiplayer, tambah server baru, lalu isi alamat dengan play.adityaanugrah.me.

Langkah 02

Daftar akun

Pemain baru ketik /register password. Ganti password dengan kata sandi kamu sendiri.

Langkah 03

Login berikutnya

Kalau diminta login, ketik /login password. Jika IP sama, server bisa auto-login sementara.

Catatan: jangan pakai password akun penting. Gunakan password khusus untuk server Minecraft ini.
